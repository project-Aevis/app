# HyperTube Music (Aevis Music)

A truly native YouTube Music client for Linux, Windows, and macOS, integrated with the Aevis Desktop Environment.

Part of the **[Project Aevis](https://github.com/project-Aevis)** suite.

## Features

- **Fully Native**: C++20 and Qt Quick, with no Electron and no bundled browser runtime.
- **Complete Library & Search**: Home, Explore, search with filters, and a library with YouTube Music tabs and sorting.
- **Audio & Video Switching**: Seamlessly switch tracks between audio and music video playback with one click.
- **Smart Audio Engine**: Gapless playback, crossfade, equalizers, loudness normalization, and timed lyrics.
- **Offline Downloads**: Smart offline playback with local library caching.
- **Material You & Aevis Theming**: Dynamic palette generation matching system colors or custom accents.
- **Full Desktop Integration**: MPRIS media controls, tray icon, media keys, and system notifications.
